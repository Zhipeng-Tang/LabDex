# Task Example Videos

Place the seven front-left-view task example videos in the following structure:

```text
task-examples/
├── atomic-skill/
│   ├── task-01/front-left-view.mp4
│   ├── task-02/front-left-view.mp4
│   └── task-03/front-left-view.mp4
├── compositional-skill/
│   ├── task-01/front-left-view.mp4
│   ├── task-02/front-left-view.mp4
│   └── task-03/front-left-view.mp4
└── long-horizon-workflow/
    └── task-01/front-left-view.mp4
```

Use MP4 files encoded with H.264 for broad browser compatibility. The generic
task directory names can be renamed to descriptive slugs after the final task
names are confirmed.
